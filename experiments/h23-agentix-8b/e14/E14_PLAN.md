# E14 实验计划: 压缩即去噪 —— 毒页感知的 agent KV 压缩
2026-09-24 立项 | 前置: E13 归档(../e13/E13_ARCHIVE.md) | 状态: 待启动

## 1. 立论(E13 幸存的独有立足点)
**毒页假设**: 多轮 agent 上下文中存在"低注意力休眠 + 高实体密度 + 任务无关"的工具输出页,
保留它们不仅浪费显存, 还**主动伤害质量**(干扰实体抢答, E13 实证 6/6 错例;
删除被判无关跨度后质量超全KV: early 70%>65%)。
**攻击面**: CommitKV(2608.07855) 的生命周期规则明确保护"低->低休眠页"不驱逐 ——
恰好把毒页永久留在缓存里。SnapKV/H2O 类按注意力质量保留则恰好保住毒页里的实体名。
**主张**: KV 压缩的判定应是三态: 已完成(丢) / 休眠待用(保) / **休眠有毒(丢, 且丢了提质)**;
毒判决 = 任务相关性判决 x 实体密度 x 删除增益测试(删除后输出对齐度不降反升)。

## 3. 我们的方法(毒页感知扩展, 叠在 CommitKV 复现之上)
对"低->低 休眠"页增加毒判决三信号:
① 任务相关性: 问题条件下的跨度判决(8B 判官, E13 实测拒判63%/召回98%; 判无关精度96%)
② 实体密度: 页内命名实体 token 占比(轻量 NER 或大写/专名启发式)
③ 删除增益: 配对测量的反向使用 —— R(E;Q) 极低且删除后对 gold 对齐度不降
   (可用教师强制 logprob 变化近似, 复用 E13 verify 机制)
判定: 休眠 ∧ (无关判决 ∧ 高实体密度) -> 降级为毒页驱逐(留存根不留实体)。
预期: 在毒页密集负载(HotpotQA改造/ToolHop干扰)上, 相对 CommitKV 复现
质量 +2~5pp(去毒) 且显存额外 -10~20%(休眠页部分转毒页)。

## 4. 实验矩阵与判定
E14.1 复现关卡: CommitKV/00902-TE 在 ToolHop+FRAMES @8B 复现出论文量级(-4pp@5x / -0.5pp@0.2);
       不达标先修复现, 不进入下一步。
E14.2 毒页验证: 毒页密集负载上 CommitKV-repro vs +毒判决, 主指标=质量差与"超FullKV"点是否存在。
E14.3 消融: 三信号逐个去除; 毒判决错杀率(gold被判毒的比例, 目标<2%)。
E14.4 规模: 8B vs 14B(毒判决质量随规模)。
**止损条件**: E14.2 中毒判决相对 CommitKV-repro 提升 <1.5pp 或错杀 >5% -> 立论不成立, 归档。
