# E16 计划: 显存事件轴的游戏内 agent 池共驻仲裁 (以 LEGO 为 baseline)
2026-09-24 立项 | 前置: E15(归档, 代理负载三难困境) + NOVELTY_AUDIT(13+占位者对质链)
| 硬件: RTX 4090(与 LEGO 同款) | 基线论文: LEGO(secs_2026/58, SJTU+MSR)

## 一、场景(承认继承, 声明扩展)
**继承(LEGO 已立)**: 单张游戏 GPU 上, 游戏渲染(60fps/16.6ms 硬 SLO) 与 LLM 推理(APM 驱动
200-600ms SLO) 共驻双满足; 云侧不可行(20-110ms 网络+成本), 渲染独占仅用 60.8% GPU。
**扩展(由 LEGO 自己的动机表驱动)**: LEGO Table I 的游戏(inZOI LLM-NPC 群/PUBG Ally 伴玩
agent/EmemeTown NPC 对话)实际是**多 agent 持久会话**负载 —— LLM 侧应为 **agent 池**:
N 个 NPC/伴玩 agent, 各持久 KV(对话历史), 动作-等待循环(工具/事件/玩家响应);
另有**突发视觉租户**(VLM 场景理解/截图分析, GB 级瞬时工作区)。
三类租户: 渲染(硬实时) x 视觉(突发大工作区) x agent 池(弹性长驻)。

## 二、问题(LEGO 框架外的约束轴)
LEGO 的显存侧全静态(权重+3.23GB adaptors 常驻, 单任务流短提示, 无 KV 状态)。
agent 池使显存从静态划分变为**事件流**: 每 agent KV 0.34GB@3k(1.7B)/1.0GB@3k(8B),
池 N=32-64 即 11-64GB 需求 >> 24GB; 视觉突发再需 6-8GB 瞬时。
**问题 = 显存事件的时机与落点管理(显存 x 延迟耦合)**: 谁的 GB 何时移动、落在谁的关键路径上。
LEGO 的机制在此轴概念性无力: 层跳不能释放停驻 KV, 时间切块不回答显存事件问题。
E15 实证(代理负载): 三难困境三边全为显存事件失败, 无一为算力轴失败(算力轴优先级即近 Pareto)。

## 三、创新点(逐条对 LEGO 差异化)
**I1 显存事件轴的问题定义 + 三难困境**: 现有三策略族在此场景必然各违一条 SLO 边
(驻留→吞吐塌[实测31 tok/s] / 重建→帧塌[miss 1.42%, 重建算力突发] / 压力→突发塌+3x离散)。
结构性失败分类学, 非工程差距。LEGO 无此轴。
**I2 预告驱动仲裁原理**: agent 状态信号(动作结束/等待开始)=显存供给**预告**;
在预告点做非破坏性让渡(停放), 显存事件全部离开关键路径。
vs LEGO 的 LR headroom 预测 = **供给侧统计预测**; 我们 = **需求侧确定性信号**。
兑现证据: 吞吐 ±1 稳定 vs 压力策略 3x 离散(确定性的直接测量)。
**I3 零精度代价的弹性**: LEGO 层跳=精度换算力(有损, 86.3%为缓解非消除);
本方案=弹性显存换共驻, **agent 输出精度零牺牲**(停放-恢复字节恒等)。
正交可组合: 醒集 decode 可叠加 LEGO 层跳进一步省算力(声明并可实验证明)。
支撑 insight: 醒集饱和物理(吞吐由醒集定, B~24饱和692tok/s@1.7B) / 速进速出干扰律 / 恢复预算不变式。

## 四、实验配置(对齐 LEGO)
- GPU: RTX 4090; 帧预算 16.6ms@60fps, 帧 miss<=1%(LEGO 同口径)
- 渲染负载: **P0 真实渲染**(vkmark/glmark2 高负载场景, 或开源游戏 demo; LEGO 用黑神话不可复现则用
  可脚本化渲染并标定至 60.8% GPU 占用与其对齐); P1 回退=定额计算代理(诚实标注, E15 现状)
- LLM: Qwen3-8B(本地) 主力, Llama3-8B(对齐 LEGO)验证; agent 池 N=32/64,
  各 3k 持久 KV, 动作周期按 APM 100/200/300 映射(动作=decode 96tok), 等待期 U(6,10)s
- 视觉租户: Qwen2.5-VL-3B(本地) 截图理解, 每 8s 突发, 工作区 6GB(P1: 真 VLM 前向; P0 先计算代理)
- **Baseline 臂**:
  B-LEGO: 静态显存驻留 + 时间轴切块调度(其调度语义复现; 层跳无训练资产则以"降层数模型"近似其
    精度-算力档位, 诚实标注) 
  B-R1 InferCept-preserve(驻留+排队) / B-RB vLLM 驱逐重建 / B-RSr kvcached 压力回收
  RS-预告(本方案) / RS+LEGO 组合臂(正交性证明)
- 指标: 三 SLO 门(帧 miss<=1% ∧ agent 动作按 APM 达标率>=99% ∧ 视觉<=2x独占)下的
  **有效 agent 吞吐(动作/分钟聚合)** + agent 任务精度(对话/动作质量, 证零牺牲主张) + 种子方差(确定性)
- 判定门槛: RS vs 每基线 一致平均>=30%(同配置同种子); RS+LEGO > RS(正交性); 精度: RS=FullKV, B-LEGO<FullKV
