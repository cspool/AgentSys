# 桌面级 GPU agent serving 经验定律库(三线交叉验证, 2026-09)
性质: 测量/刻画类贡献。每条定律给出: 表述 / 三处独立复现证据 / 与现有理论的区别。

## 律1 择时收益律: 可避免损失 ∝ 作用时段占比 x 候选时刻产出率差 − 开销
- 证据A(抢占线): ΔG_v ≈ duty x Δr/r̄, 预测56.4pp vs 实测52.8pp(6%误差); 三点谱系 1x/6.2x/∞ -> 0-2%/+59%/+82%
- 证据B(投机线): B3 上限=尾部占比x接受率, 实测逐档吻合(2.8%->0.8%, 36.5%->7.4%)
- 证据C(共驻线): 让位时机被动vs主动: 突发关键路径上让位 = 视觉+26%时延
- 区别: 非单场景启发式, 而是跨抢占/投机/仲裁三语境的同构律; 现有工作各自局部(InferCept成本模型/投机解码接受率)无统一表述

## 律2 恢复预算不变式: 需重建状态量 x 单位重建成本 ≤ 外部等待窗 ⇔ 状态可临时化
- 证据A: E14 量化(8B 150ms/1k, 窗1s->7.2k tok); 前缀长度使单价+50%(8k前缀)
- 证据B: E13-J 按需换页死于窗外重建(全程存根无法补回整合态)
- 证据C: E15 RB臂重建债务实测(醒付145ms, 池64下仍存活但吞吐仅RS的37%)
- 区别: Chronos 的 WCRT 界针对请求调度; 本律针对**状态驻留决策**(什么可以不留), 且给出跨层常数表(重建/换出/文本三层实测)

## 律3 干扰律: 共驻干扰代价 ∝ 重叠时长 x 强度, 速进速出优于细水长流
- 证据A(E13): 后台prefill chunk 512/128/64 -> 前台膨胀+14/+24/+47%, 加gap更糟(+73%)
- 证据B(E15): 视觉切块让出(E2臂)反而100% miss(切块拉长占用窗); 大块+优先级最优
- 证据C(E11): 共驻prefill 1.7B+0.9% vs 8B+14-20%(强度项)
- 区别: 与直觉(细粒度=友好)相反; Heimdall的切块结论适用于无优先级单队列移动GL, 在桌面CUDA优先级流下反转 —— 边界条件明确

## 附: 饱和-醒集物理(共驻吞吐的决定量)
decode 饱和点(1.7B@3k: B~24=692tok/s; 8B@3k: B~13-16), 吞吐由醒集饱和度决定而非显存总量;
驻留语义使醒集塌缩(35席位->8醒), 停放语义拉满(+171%实测)。
