# E15 创新性严格审查比对 (2026-09-24, 对抗性)
方法: 同义词族扫描(coordination/contention/QoS/ballooning/elastic/virtual-memory)
+ 移动端/实时系统老线回溯 + 机制归属逐条判决。教训来源: E13/E14 撞车。

## 主张 x 最近邻 判决表
| E15 主张 | 最近邻 | 判决 |
| ① 渲染硬SLO+推理共驻, 优先级+切块仲裁 | **Heimdall(MobiCom'20)**: AR渲染+多DNN同卡, 帧30->12崩塌, 伪抢占切块+动态优先级, 帧救回30fps/DNN尾延迟↓15x | **死**。E15 v1 = 桌面CUDA上的再推导(确认性价值); "计算维P近Pareto"与其结论同构 |
| ② KV显存弹性作为共驻让位机制 | **kvcached/Prism(2505.04021)/eLLM(2506.15155)**: OS式虚拟内存KV, 弹性分配/回收, 模型间动态共享, 生产10K+卡, TTFT 2-28x | **死**。且其机制(虚拟内存重映射)强于我们的D2H拷贝; 我们的RS=穷人版kvcached |
| ③ 异质SLO多agent单卡联合仲裁"无人做" | Heimdall(渲染+DNN) + RT-GPU综述(2505.11970) + Miriam(2307.04339 弹性kernel实时多DNN) + VUDA(机制层) | **原表述死**(检索不足的断言); LLM-agent特有结构(KV状态/工具等待)x硬RT共驻的组合slice仍窄开 |
| ④(幸存候选) agent状态驱动的**主动**停放 vs 压力驱动的**被动**回收 | kvcached/Prism 回收均为负载/压力触发(被动); 无人绑定 agent 工具等待信号做预让位 | **窄条存活**: 我们RS臂视觉fail 18%实证被动回收在突发关键路径上的脆弱; 主动停放使突发到达时显存已就位。消融 RSr(被动) vs RS(主动) 进行中 |

## 结论
E15 原三主张经严格审查: ①②死于占位, ③表述不成立。
幸存创新窄条 = **弹性时机**: 让位发生在 agent 进入等待时(信号驱动, 关键路径外)
而非资源压力到达时(突发关键路径上)。与本仓一贯的"择时"主线同构(W=0 定价的显存版)。
该窄条单独不足以成文; 作为机制库组件归档, 或并入更大的 agent-serving 叙事。
诚实评级: E15 = 工程验证 + 确认性再推导 + 一条窄幸存条。

## 主张④ 实测判决(RSr被动 vs RS主动, 90s x 2种子)
| 臂 | LLM tok/s | 视觉时延 | 视觉fail |
| RSr 被动(突发时才停放) | 27±14 | 1031ms | 0 |
| RS 主动(等待即停放) | 216±53 | 820ms | 4 |
解读(诚实):
① 被动策略最终陷入显存耗竭 thrash(等待者滞留 -> 22GB 饱和 -> decode/重组全程 OOM 挣扎)
  => LLM 崩至 27; 主动停放避免之(+700%)。
② 突发时停放上关键路径: 视觉 +211ms(+26%) —— "让位时机"的直接代价实证。
③ 但 RS 的 fail 4 是分配器碎片伪影(RSr 恰因突发路径 empty_cache 而 fail 0), 非机制本质。
④ **关键保留**: RSr 模拟的是"无策略惰性", 不是 kvcached 的压力驱动连续回收;
  严格击败 kvcached 需集成其虚拟内存机制作 baseline —— 本轮未做, 主张④ 仅获方向性证据。

## 最终评级(严格口径)
30%指标: 达成(核心消融 RS vs RB +171%; RS vs RSr +700%)。
创新性: **原主张①②③死, ④方向性存活但证据不足以立论文级主张**。
E15 定位 = 工程验证 + Heimdall/kvcached 时代的确认性再推导 + 一条待严格验证的窄条(弹性时机)。
若继续: 必须以真 kvcached 集成为 baseline, 在其上做"agent等待信号驱动的预让位"增量。
