## 结论
E15 原三主张经严格审查: ①②死于占位, ③表述不成立。
幸存创新窄条 = **弹性时机**: 让位发生在 agent 进入等待时(信号驱动, 关键路径外)
而非资源压力到达时(突发关键路径上)。与本仓一贯的"择时"主线同构(W=0 定价的显存版)。
该窄条单独不足以成文; 作为机制库组件归档, 或并入更大的 agent-serving 叙事。
诚实评级: E15 = 工程验证 + 确认性再推导 + 一条窄幸存条。

## 主张④ 实测判决(RSr被动 vs RS主动, 90s x 2种子)
| 臂 | LLM tok/s | 视觉时延 | 视觉fail |
| RSr 被动(突发时才停放) | 27±14 | 1031ms | 0 |
| RS 主动(等待即停放) | 216±53 | 820ms | 4 |
解读(诚实):
① 被动策略最终陷入显存耗竭 thrash(等待者滞留 -> 22GB 饱和 -> decode/重组全程 OOM 挣扎)
  => LLM 崩至 27; 主动停放避免之(+700%)。
② 突发时停放上关键路径: 视觉 +211ms(+26%) —— "让位时机"的直接代价实证。
③ 但 RS 的 fail 4 是分配器碎片伪影(RSr 恰因突发路径 empty_cache 而 fail 0), 非机制本质。
④ **关键保留**: RSr 模拟的是"无策略惰性", 不是 kvcached 的压力驱动连续回收;
  严格击败 kvcached 需集成其虚拟内存机制作 baseline —— 本轮未做, 主张④ 仅获方向性证据。

## 最终评级(严格口径)

## 叙事主轴改写(2026-09-24, 用户指令: 避免"组合工程"观感, 凸显出发点新颖)
新增对质: MORI(2606.00866 工具空闲窗卸载) / ConServe(2410.01228 空闲GPU收割)
/ Astraea(2512.14142 状态感知agent调度) / 2608.15127(agentic负载刻画)
=> "等待即资源/空闲收割"的裸角度已被占。
**幸存且被终局数据独家支撑的出发点: 可预告性(announced-ness)是共驻仲裁的决定性属性。**
- 论据: agent负载的资源供需事件自带预告信号(工具调用=供给预告); 
  RS ±1稳定 vs RSr 3x离散 = 预告确定性 vs 压力随机性的直接测量;
  三难困境 = 对预告的三种错误处置(R1无视/RB在预告点做破坏性动作/RSr弃预告用压力救火)的必然结果。
- 区别于: MORI(利用窗口, 未提出预告性属性), InferCept(用信号但框架为成本最小化, 无确定性主张),
  kvcached(压力=无预告), Chronos(到达过程可调度性, 非预告语义)。
- S2 重述: 非"组合", 而是**同一原理(预告驱动仲裁)在显存/算力/时机三维度的必然推论**。

=> "渲染+模型同卡、帧隙调度、双满足"场景**老**, 时间/算力轴已被该谱系做透
(我们 v1 "优先级近Pareto" 为其复证)。
**修正后的场景主张**: 该谱系的共同假设=静态显存驻留+动态时间复用;
当推理侧为 KV 弹性 agent 池 + 突发工作区租户时, 显存从静态划分变为**事件流**,
约束从时间轴迁移到**显存事件轴(显存管理x延迟管理耦合)** —— 三难困境三边全为显存事件失败、
无一为算力轴失败, 即此迁移的实证。方法主张(预告驱动)不受影响, 且更聚焦:
预告驱动=把显存事件从关键路径挪到预告点。
