# 多格创新审阅表(2026-09-24) —— 每格: 类型/创新判定/消融证据/效果显著性
纪律: 审查先于实验; 负结果与正结果同等入档。

## G1 自干扰争用螺旋 (**新问题**)
- 判定: 存活。VLA/agent文献仅"推理时延->观测陈旧"单向常识(vla.cpp等); 共驻致陈旧度成为
  负载函数、形成正反馈环、存在失稳阈值 —— 无人做。
- 消融(A臂, agent数扫描, τ=1600ms/独占94%通过): 1ag 27.2 goodput/94% -> 2ag 19.6/35%
  -> 3ag 1.3/2% -> 4ag **0.0/0%**, 陈旧度 1050->10592ms, 重试放大36x。
- 判定: **2->3ag 锐利相变(环增益跨1)**, 新问题定量成立。

## G2 截止期 slot 仲裁 (**新方法**)
- 判定: 存活(预告驱动原理第三落点: 观测-动作窗=自我预告需求窗)。
- 消融 vs baseline(4ag): A 自由 0.0 / B 静态限速(公平调参 rate∈{2.2,4,6,9}s, 最优6s) 4.8
  / **C slot 36.8-44.1(3种子) 90-96%**, 重试放大 1.1x, 帧miss 0。
- 效果: **C最差种子 vs B最优调参 = +662%**; 且 C(36.8-44.1) > solo(27.2) —— 串行化反而流水化。

## G3 窗口调度策略消融 (**方法内消融, 负结果**)
- 臂: C 全局互斥 / D EDF截止期排序 / E EDF+并发2。
- 同构τ(4ag): C 36.8 / D 3.3 / E 1.3 —— **并发让位给互斥**(E 最差: 并发2 使双方都超窗, 重试32x);
  D 劣于 C 因排队抖动。
- 异构τ(2紧急1.6s + 4宽容5s, 6ag): C 46.1 总/紧急96% vs D 39.4 总/紧急96%(紧急goodput D 16.7 > C 15.3)。
- 判定: **EDF 仅在异构截止期下于紧急类微弱占优(+9%紧急goodput), 总吞吐反降16%** =>
  复杂排序在此问题无收益, 简单互斥即近优。诚实负结果, 支持"仲裁应简单"。

## G4 双神经租户共驻 (**新场景, 负结果->律的精化**)
- 场景: 神经渲染(10fps/100ms预算, 每帧40/70/90ms串行重核) x agent LLM decode。
- 消融: 三臂(A2自由/P2优先级/G2门控) x 三密度 = 9配置, **帧miss 全部 0.00%**,
  P99 37/66/85ms 三臂一致; LLM吞吐 281/176/102 随密度线性下降(纯算力竞争, 无排队病理)。
- 判定: "神经渲染使优先级定律失效"假说**被证伪**; 反得更基本的假说:
  **干扰由干扰者核粒度 vs 受害者松弛决定, 非总负载** (E15小核场景自由竞争帧崩 vs 此处粗核场景
  自由竞争无损)。
- 最终: G4 收为"神经租户场景(粗帧+细核)无需仲裁"的负结果, 其价值并入 G5。

## G5 粒度不对称律 (**新 insight, 统一两场景**)
律: **共驻干扰由"干扰者核粒度 vs 受害者松弛"决定, 与总负载无关**;
需要仲裁 iff 干扰者单核时长可观地占据受害者松弛。
- 消融A(固定帧70ms/松弛30ms, 扫干扰者核粒度 prefill chunk):
  | chunk | A2自由 帧P99 | P2优先级 帧P99 | 自由臂P99膨胀 |
  | 256 | 65.9ms | 65.5ms | +0.6% |
  | 1024 | 71.9ms | 68.7ms | +10% |
  | 4096 | 88.8ms | 70.1ms | **+36%**(优先级仅+7%) |
  => 优先级的价值随粒度单调增长(5x降低干扰), 与律预测一致。
- 消融B(决定性: 松弛压至10ms + 最粗核4096):
  **A2 自由竞争 帧P99 112.0ms / miss 14.06% 破线; P2 93.1ms / 0.00%; G2 90.8ms / 0.00%** —
  同一系统同一负载, 仅粒度x松弛改变即从"无需仲裁"跃迁到"不仲裁必崩"。
- 统一解释: E15(小核受害者 x 粗核干扰者->自由竞争帧崩 8%) 与 G4(粗帧 x 细核decode->自由竞争无损)
  两个看似矛盾的观测, 由本律同时解释; 也精化了 E13/E15 的"速进速出"律(给出其适用判据)。
- 实用推论: **可预测"是否需要调度器"** —— 给定核时长分布与松弛, 无需实测即可判定;
  这是区别于所有既有共驻工作(它们默认总需要仲裁)的工程价值。
