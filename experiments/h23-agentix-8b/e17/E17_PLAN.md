# E17: 自干扰闭环 —— computer-use agent 与其宿主 GPU 的争用反馈螺旋
2026-09-24 立项(经 E16 §八 管线深审选出) | GPU0 | 状态: 最小实验构建中

## 深审判决(三格)
C10 死: expert-vs-KV 权衡已密集占位(vLLM RFC/FineMoE EuroSys26/Kernel-Managed Tiering/LMCache MoE)。
C5 存活为后备: 单世界模型实时部署被全栈协同占位(ZYT/MoWorld/ABot-World-0 19GiB@5090),
双神经租户共驻空白且动机极强(世界模型近吃满整卡而交互世界需要agent大脑)。
**C1 当选**: VLA文献知"推理时延->观测陈旧"(单向常识); **争用反馈螺旋**(共驻特有)无人做:
agent推理抢宿主GPU -> 渲染慢 -> 截图旧 -> 动作错 -> 重试 -> 负载更高。桌面computer-use语境空白。

## 新问题定义
自干扰: agent 的计算足迹扰动其自身观测流。陈旧度不再是常数(推理时延)而是**负载的函数**,
构成正反馈环, 存在失稳阈值。稳定性(而非吞吐)成为第一设计目标。
预告驱动第三落点: agent 的观测-动作窗是**自我预告的需求窗**(截止期已知), 仲裁应围绕它排布。

## 最小实验(GPU0)
UI代理: 60fps渲染线程维护目标状态(帧号=时钟); "截图"=捕获帧号; 动作有效 iff
(动作时帧号-捕获帧号)<=τ(陈旧窗)。agent: 真实LLM decode(观测->动作, K token);
失败即重试(螺旋驱动)。多agent+背景负载制造争用。
臂: A 自由竞争(预期: 失稳螺旋, 成功率崩塌) / B 静态限速(每agent固定推理配额)
/ C 观测截止期感知仲裁(agent声明窗, 窗内独占slot+渲染保优先, 窗间让出)。
指标: 任务goodput(成功动作/分钟) + 成功率 + 螺旋定量(重试放大系数, 负载-陈旧度环增益)
+ 帧SLO。显著性目标: C vs 最好基线 goodput 显著提升, 且 A 的失稳阈值被定量刻画(环增益>1判据)。
