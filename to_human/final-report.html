研究问题

Program-aware、heterogeneous-flow-aware 与 semantic tile scheduling 能否在真实系统接口下组合，并让 reactive urgency 从 Agent 程序一直传到 ME/VE/DE？结果表明可以，但收益受 call release、tile 粒度、DDR 瓶颈和 dataflow 约束。

两个决定性负结果

过小 tile

2–16-cycle lowering 使 7-cycle TISA dispatch 反而拖慢执行。保留 run 005 后，按论文 10³–10⁵-cycle 粒度修正才得到 1.324×。

晚释放的 priority

只在 flow/task/tile 下传 urgency 无法弥补 ATLAS 晚释放。Urgency 必须成为 call scheduler 第一排序键；run 007 作为反例保留。

边界

A100 aggregate 与私有 Sniper 结果属于 paper-parameterized replay；Agent.xpu/TISA 属于 source-grounded trace/cycle simulation；Rocket+Verilator 和 Ramulator2 是真实开源 simulator 执行。两张 RTX 4090 没有被用来替代 A100、Intel NPU 或 Epoch 真硅片。
